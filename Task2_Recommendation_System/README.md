NETFLIX MOVIE RECOMMENDATION SYSTEM 

DESCRIPTION 
This is simple rule-based movie recommendation system developed using python the program recommends movies based on the genere selected by user it provides recommendations for action,comdey,horror,romance,kids genres 
the applications runs continuously using a while loop until the user enters "bye" or exit to quit 

FEATURES 
Recommends movie based on user selected genere 
Supports five genres:
Action 
Comdey 
Horror 
Romance 
Kids

Allows users to get multiple recoomendations without restarting the program 
Exits gracefully when the user types bye or exit 

HOW TO RUN 
save the file as recommendation system.py
open the cmd in the project folder 
run: python recommendation system.py
