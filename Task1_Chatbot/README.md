AI Chatbot with Rule-Based Responses

DESCRIPITION
 A simple AI Chatbot bulit using python that responds to predefined user inputs using rule-based logic The Chatbot can answer basic questions about Artificial Intelligence(AI),Machine Learning (ML) and AI applications.

 FEATURES
 Greet Users 
 Explains AI ,ML and applications of ML
 handles unknown inputs gracefully 
 exists when the user types bye 

 TECHNOLOGIES USED 
 Python 3

 HOW TO RUN 
 1. Save the file as chatbot.py
 2. Open Cmd in the project folder
 3. run: python chatbot.py
