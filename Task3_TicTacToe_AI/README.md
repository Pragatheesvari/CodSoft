Tic-Tac-Toe AI

 DESCRPITION 

This project is a Python-based Tic-Tac-Toe game where a human player competes against an AI. The AI uses the Minimax algorithm, making it an unbeatable opponent. The project demonstrates game theory, recursion, and decision-making algorithms.

FEATURES

- Human vs AI gameplay
- Unbeatable AI using Minimax Algorithm
- Detects winner and draw
- Validates user input
- Interactive command-line interface
  
HOW TO RUN
save the file as TIC_TAC_TOE.py open the cmd in the project folder run: python TIC_TAC_TOE.py
